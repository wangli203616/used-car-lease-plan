# 二手车以租代购 · 可行性研究与落地方案

针对「资金方出钱把车买到公司名下 → 租给客户 36/48 期 → 租金测算年化收益 30%、资金方 12–15%」这一结构做的尽调备忘，含四川落地路径。

> **「30%」的口径**：不是报给客户的利率，而是把 36 期租金按融资额折现算出的 IRR。产品对外只报月租金，合同里不出现百分比。同一个数从客户侧看就是他承担的资金成本——一枚硬币的两面。

## 一句话结论

这个模式能做，但不能按原方案做。原方案的「30% − 13.5% = 净赚 16.5%」高估了约 5 倍：单台 10 万元车、20% 首付、36 期，3 年净利 9,373 元，占车价 9.4%，折年 **3.1%**。

## 三个核心判断

1. **利差是幻觉。** 客户 3 年多付的 50,796 元里，43.6% 是资金方利息、25.6% 是运营成本，公司只剩 18.5%。利润本质来自首付减运营成本，不是利差。

2. **税务结构决定生死。** 有形动产融资租赁「增值税实际税负超 3% 即征即退」已被财政部/海关总署/税务总局 2025 年第 10 号公告废止，自 **2025-11-01** 起执行。二手车几乎无进项，13% 销项使直租单台净利变成 **−648 元**。改走「二手车经销 + 分期收款 + 所有权保留」，增值税 0.5%，单台净利 **+9,373 元**。

3. **「车在公司名下就能随时收车」是误解。** 2024–2025 年杭州、兰州、上海、鱼台等地判例：夜间拖车被认定侵权，甚至按盗窃、寻衅滋事追刑责；有合同授权也不免责。合规路径只有协商 → 公证 → 诉讼保全 → 强制执行。
